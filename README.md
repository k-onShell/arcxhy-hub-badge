## 📥 Installation

1. Clone the repository:

```bash
git clone https://github.com/k-onShell/arcxhy-hub-badge.git
```

2. Open the project folder:

```bash
cd arcxhy-hub-badge
```

3. Run the Python script:

```bash
python archy-hub.py
```
